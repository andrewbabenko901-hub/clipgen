# ClipGen

Параметрический генератор автомобильного пластикового крепежа.

**Демонстрация:** https://andrewbabenko901-hub.github.io/clipgen/

Подбираешь размеры по своей детали, смотришь модель в 3D, скачиваешь STL и
печатаешь. Есть каталог реальных артикулов с фотографиями и поиск по замерам
штангенциркулем.

Модели построены по опубликованным размерам из каталогов поставщиков.
Ни один чужой STL не использовался.
